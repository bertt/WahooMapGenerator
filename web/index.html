Conversion

OSM PBF → Wahoo map

Extracts one z=8 tile from an OpenStreetMap extract and writes a Wahoo (mapsforge v3) map file.

Get one from Geofabrik (e.g. Europe → Netherlands). Geofabrik does not allow downloads from other web sites, so download it manually first.

Click a cell in the z=8 grid to select a tile.

The tile numbering is the one used by the official Wahoo tile files (…/tiles/8/<col>/<row>.map.lzma); these are standard XYZ tiles at zoom 8 (about 150 × 100 km each).

The file is read twice (relations first, then features). A country extract can take a few minutes and up to ~3.5 GB of memory — use a desktop Chrome, Edge or Firefox.

Result

Put the map on your Wahoo

  1. Download the .map.lzma file. The Wahoo file layout is tiles/<col>/<row>.map.lzma; for tile 8/131/84 that is 84.map.lzma in a folder 131.
  2. Connect your ELEMNT to your computer with its USB cable.
  3. Open the device as a drive (or use Android File Transfer / OpenMTP on a Mac) and copy the file to TODO: path on the device.
  4. Safely eject the device, restart it and check the map in the navigation view.

Back up the original map files first. Wahoo may change how maps are loaded at any time. Use at your own risk; not affiliated with Wahoo Fitness.
